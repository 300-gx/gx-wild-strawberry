# 开发路线与验收状态

## 已有（v0.1 原型）
- 首页视觉、作品卡片、元数据搜索与标签筛选。
- 作品详情弹窗、主题切换、随机推荐/评论、演示点赞与收藏。
- 响应式布局。

## v0.2 本次交付
- 整理为仓库可用结构：`site/`、`content/`、`docs/`、`scripts/`、`.github/workflows/`。
- 提供作品与作者数据样例。
- 提供内容字段校验脚本；GitHub Actions 在部署前执行校验。
- 提供 GitHub Pages 自动部署工作流。
- 提供面向非开发者的注册、建仓库和部署说明。

## 尚未完成，不能对外宣称已具备
- Hexo 模板化构建和由 Markdown 自动生成作品详情/作者/标签页面。
- Decap CMS 登录、作者身份绑定、作者只能编辑自己的作品。
- 评论、嵌套回复、匿名评论、点赞/取消点赞、收藏和举报的真实后端。
- 图片上传、水印处理、灯箱多图集。
- 每日原作截图轮换、RSS 全站/作者/标签 feed。
- 每周邮件汇总、订阅/退订、数据库备份和一键导出。
- IP 限流、验证码、User-Agent 规则与滥用监测。

## 下一阶段建议
1. 先让静态网站通过 GitHub Pages 发布，确认域名和访问路径。
2. 把现有页面迁入 Hexo 主题，确保 Markdown 作品可以自动生成详情页、作者页、标签页和 RSS。
3. 在选定动态服务后设计登录与权限，必须测试作者 A 无法修改作者 B 的内容。
4. 再逐项接入互动、图片处理、邮件和备份。
